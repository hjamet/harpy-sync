# Tier 1

Le personnage gagne un bonus de +1 à tous les jets visant à ne pas éveiller les soupçons.

# Tier 2

Pour chaque temps passé avec sa cible, l'espion gagne un bonus de +1 sur un jet en opposition unique.

# Tier 3

Une fois par session, l'espion peut se renseigner sur un personnage. S'il y a quelque chose à découvrir, il obtiendra un indice la session suivante sur un jet de perception aveugle.
