# 2. Notoriété 

![[test-vault-asharde-v1/_attachments/2__notori_t___profile_pmjq7p.jpg]]

Le personnage est influent auprès des membres d'un milieu donné

<!-- harpy:page uid="qcvAMYiRivUFlqzI8tn7" name="Descrtiption" type="standard" -->
# Descrtiption

<!-- harpy:chunk uid="CMzwjHYXe3cnAm0rq2TT" type="text" -->
<blockquote>

Le personnage choisit un domaine parmi :

- **Classe sociale** : nobles, roturiers, serfs, esclaves, etc.

- **Profession** : chevaliers, artisans, marchands, paysans, mages, etc.

- **Origine ethnique** : différentes races fantastiques ou groupes culturels.

- **Affiliation religieuse** : cultes, ordres religieux, panthéons.

- **Guilde ou corporation** : associations professionnelles ou magiques.

- **Région d'origine** : provinces, royaumes, cités-états.

- **Lignée familiale** : grandes maisons, clans, dynasties.

- **Capacités magiques** : types de magie, puissance, spécialisation.

- **Statut militaire** : rang dans l'armée, mercenaires, gardes.

- **Éducation et connaissances** : lettrés, illettrés, savants, sages.

Les membre du domaine choisi sont toujours mieux disposés de **X** points envers le personnage.

</blockquote>
