# 4. Interdiction Traumatique

![[test-vault-asharde-v1/_attachments/4__interdiction_traumatique_profile_u5piwl.jpg]]

Le personnage interdit de manière durable à quelqu'un d'effectuer une action précise

# First page

<blockquote>

Par une **Action normale **en **Temps Calme**, le personnage impose un traumatisme à sa cible, la forçant à réussir un test d'**Intelligence **de difficulté égale à X * 2 + *Jet d'intimidation du personnage *pour effectuer une action précise. Cette "malédiction" dure tant que la cible n'est pas parvenue à réussir son test d'**Intelligence**.
