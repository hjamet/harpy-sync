# 4. Fais le pour moi

![[test-vault-asharde-v1/_attachments/4__fais_le_pour_moi_profile_7cc568.jpg]]

Donne un bonus à ses alliés pour la réalisation d'une action précise

<!-- harpy:page uid="ylG9XzaPDq12hQl3374t" name="First%20page" type="standard" -->
# First page

<!-- harpy:chunk uid="vTs0peUKLxmsLaB3qLJ7" type="text" -->
<blockquote>

Par une action Normale d'un Temps d'Action, le personnage peut indiquer une action précise à quelqu'un. Ce dernier gagne alors un dé bonus non cumulable avec aucun autre dé bonus à toutes les actions pointant vers cet objectif.

</blockquote>
