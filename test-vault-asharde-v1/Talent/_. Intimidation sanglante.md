# ?. Intimidation sanglante

Le personnage est encore plus terrifiant lorsqu'il est blessée

<!-- harpy:page uid="9K8kDpHfZK2rM6NgQrLp" name="Description" type="standard" -->
# Description

<!-- harpy:chunk uid="8TYonTBoJUIoOjh6XCGg" type="text" -->
<blockquote>

Lorsqu'il subit un affaiblissement, le personnage peut dépenser son action pour tenter un test d'intimidation. Il gagne des dés bonus en fonction de l'affaiblissement subis.

Si l'affaiblissement est temporaire, il gagne 1 dés bonus. 

Si l'affaiblissement est mineur, il gagne 2 dés bonus.

Si l'affaiblissement est majeur ou définitif, il gagne 3 dés bonus.

</blockquote>
