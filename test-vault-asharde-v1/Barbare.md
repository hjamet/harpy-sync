# Description

<!-- harpy:chunk uid="6jZ8mVehOV98WBkmhUsS" type="text" -->
# Tier 1

À chaque attaque du barbare, sur un jet de chance réussi, les affaiblissements du personnage augmentent d'un tier jusqu'à la fin du combat.

# Tier 2

Lorsqu'une de ses caractéristiques atteint 1, les affaiblissements supplémentaires subis sont retransmis à la Chance avant la Constitution.

# Tier 3

Tous les affaiblissements de chance subis par le barbare sont temporaires.
