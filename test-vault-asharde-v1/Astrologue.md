# Description

<!-- harpy:chunk uid="IfdtGDCTzgKriNXbTJZ9" type="text" -->
# Tier 1

Autant de fois que son score de Foi par jour, l'astrologue peut poser une question en oui ou non dont la réponse est probablement juste à 50% + 10 x Érudition / 2 jusqu'à un maximum de 85%.

# Tier 2

À chaque session, l'astrologue a une vision, sous la forme d'une image qu'il est le seul à voir et qui dévoile dans une certaine mesure les avenirs les plus probables.  L'image est montrée fugitivement.

# Tier 3

Sous les Astres, l'Astrologue peut ajouter son score d'Érudition comme dés supplémentaires lorsqu'il lance des sorts.
