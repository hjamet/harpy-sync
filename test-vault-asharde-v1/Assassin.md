# Tier 1

Les scores d'adversaires pris au dépourvu par les actions de l'assassin sont réduits de 1.

# Tier 2

Lorsqu'il tue sa cible, l'assassin obtient un tour supplémentaire (max 1 par tour).

# Tier 3

L'assassin choisit les types d'affaiblissements qu'il inflige.
