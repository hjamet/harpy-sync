# Description

<!-- harpy:chunk uid="qXZKAgoaW8iOQ8vx8iMa" type="text" -->
# Tier 1

Le personnage peut lancer un sort gratuitement en tirant sa flèche. Le point d'application du sort sera le point d'impact de la flèche. Une telle flèche demande une action longue.

# Tier 2

Le personnage ignore tous les abris. Tant qu'il s'ait où se trouve sa cible, qu'elle est à portée et qu'il existe un chemin par lequel pourrait passer son projectile, il peut la tirer sans malus.

# Tier 3

Les flèches enchantées du personnage peuvent toucher une infinité d'ennemis différents à chaque fois.
