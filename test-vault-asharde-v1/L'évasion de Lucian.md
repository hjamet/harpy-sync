# L'évasion de Lucian

Un sbire de Lucian se tue avec une dague enchantée pour permettre àson maitre de contacter un joueur

# First page

<!-- harpy:chunk uid="gtvJW1pVpalmb2LTc5T2" type="text" -->
Les joueurs se trouvent à Cavahan.
Probablement enfermés dans les prisons de la ville.
Un sbire de l'Empereur perdu Lucian se plante une dague enchantée dans le ventre.
Ce sbire meurt dans d'atroces souffrances.
Le sacrifice permet à Lucian de communiquer avec le joueur par télépathie.
Lucian peut agir à travers le joueur, notamment de lancer des sorts.
Lucien guide le joueur jusqu'à sa prison flottant au-dessus de la ville de Cavahan.
Lucian pousse le joueur à l'aider à s'évader.
Lucian n'est pas tout à fait blanc, mais aide les joueurs.
La manière de communication de Lucian est extrêmement glauque.
