# Tier 1

Le personnage peut créer un maximum d'une dose d'une potion en une action normale d'un temps d'action. Cette dose doit être utilisée le Temps suivant, sans quoi elle deviendra inerte.

# Tier 2

Les jets d'alchimie du personnage ont une difficulté réduite de 2.

# Tier 3

Le personnage peut remplacer un unique ingrédient de sa préparation par un autre.
